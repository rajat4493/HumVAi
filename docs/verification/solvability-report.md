# Level solvability report

Generated by `npm run verify:levels` (exhaustive breadth-first search over the real engine, run phase analysed in isolation).

- **Dead** = reachable world state from which no win exists (only RESET escapes). **Irreversible** = state that can never return to the start without RESET (a pushed block or a spent rune is irreversible but not dead).
- **Shift essential** = the level has a rule change *and* no action sequence that avoids it can win (proved by pruning every epoch-1 state and re-searching). "by budget" = a change-free route exists but needs more actions than the run allows.
